# Can a small language model be trusted with a phylogenetic tree?

An interactive public study. Five small open language models (Qwen 2.5 3B, Llama 3.2 3B and 1B,
Gemma 3 4B, DFM Mimir 1B) answer 120 computed-truth questions about phylogenetic trees under
three conditions: unaided, after declaring whether they can answer without tools, and as an agent
operating the phylo2vec library (Penn, Scheidwasser, Khurana, Duchêne, Donnelly and Bhatt,
Systematic Biology 2025) through a plain text tool protocol. The agent condition runs twice,
differing only in whether tool errors are terse or name the missing field, which turned out to
be one of the study's findings.

Live: https://bolgacg.github.io/phylo-agent-demo/

Companion to https://bolgacg.github.io/daisy-tools/ (same five models, same honesty probe,
Danish facts instead of trees).

## Layout

- `study/gen_tasks.py`  seeded task generation; truths computed by phylo2vec and an independent
  Newick parser that must agree
- `study/tree_kit.py`   the parser, the truth functions, and the agent's tool dispatch
- `study/runner.py`     the four conditions against a local llama.cpp server
- `study/score.py`      exact-match scoring (topology-aware for tree answers), honesty and
  agent-behaviour statistics
- `study/run.sh`        serve each model, run everything, score
- `docs/`               the page; `docs/data.js` is generated by `study/build_page_data.py`

## Reproduce

```
cd study
python3 -m venv .venv && .venv/bin/pip install phylo2vec numpy requests
bash run.sh            # needs llama.cpp's llama-server and the five GGUFs
python build_page_data.py > ../docs/data.js
```

All prediction logs, transcripts included, ship in `study/` as `pred_*.scored.jsonl`.
No real biological data anywhere: every tree is synthetic. Bolgaç Gülen, September 2026.
